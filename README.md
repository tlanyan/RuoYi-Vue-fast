# 项目简介

Ruoyi 项目有多个版本，但是常用的[Ruoyi](https://github.com/yangzongzhuan/RuoYi)、[Ruoyi-Vue](https://github.com/yangzongzhuan/RuoYi-Vue)和[Ruoyi-Cloud](https://github.com/yangzongzhuan/RuoYi-Cloud)版本均使用Java 8、SpringBoot 2和Vue2。都2025年了，不得不说这些技术太老旧或严重过时了。

本人偶尔也用Ruoyi快速搭建后台系统，偏向于用新技术因此一般使用Ruoyi-Vue-fast + Ruoyi-Vue3的组合。遗憾的是使用Vue2的Ruoyi-Vue有[SpringBoot 3分支](https://github.com/yangzongzhuan/RuoYi-Vue/tree/springboot3)，但是纯后端的[Ruoyi-Vue-fast](https://github.com/yangzongzhuan/RuoYi-Vue-fast)没有。为此本人把Ruoyi-Vue-fast（本项目）迁移到了SpringBoot 3和JDK 17，同时默认使用Vue3，因此建议配合[Ruoyi-Vue3](https://github.com/yangzongzhuan/RuoYi-Vue3)使用。

本项目会不定期与上游的Ruoyi-Vue-fast同步。使用过程中有问题请在Ruoyi-Vue-fast项目中发issue，同步问题在本项目提。另外原版Ruoyi项目不止在Github上有仓库，也在国内的Gitee等上面有，因此README中的链接跳来跳去。本项目默认只在Github上，不会有各种跳来跳去的链接。
